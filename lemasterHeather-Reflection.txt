I chose the Unique Word Count problem. I used a set as the main data structure to solve the problem due to their speed, simplicity, and lack of duplicates. Sets are also easy to implement in Python, which influenced my decision since I was under a time limit. Sets work well for problems where the number of unique values need to be counted, since the length of a set reveals the number of unique values. Since I was working with strings, I needed to make sure I accounted for capitalization and punctuation. Otherwise, the same words would be counted multiple times. The words or original string did not need to be stored, and their order did not matter, which also made a set ideal to solve the problem.

	The main compromise I made due to the time limit was not making separate functions for each task in the program. Ideally, I would have implemented a separate function to handle error checking, such as when I checked the data type of the input or if the string was empty. Additionally, I would have added a function to handle the output, since the bottom of the program has several long print statements. Ensuring each function only does one job makes the program easier to understand, debug, and expand.
